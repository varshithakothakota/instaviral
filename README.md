## ✨ What is InstaViral?

InstaViral is a Computer Vision experiment inspired by a viral Instagram visual effect.

It uses a webcam to track hand movements and gestures, then uses that information to create an interactive effect on the live camera feed.

The idea was simple:

**See something cool → figure out how it works → build it.**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/instaviral.git
cd instaviral
```

### 2. Create a virtual environment

```bash
py -3.12 -m venv .venv
```

### 3. Activate the environment

**Windows:**

```bash
.venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the project

```bash
python main.py
```

Make sure your webcam is connected and camera access is enabled.
